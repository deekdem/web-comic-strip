# Superheroes in Detention

This project is a four-panel comic strip webpage created using HTML and CSS.

The comic is about two teenage superheroes who are stuck in after-school detention after trying to save their school. While in detention, they discover that the Joker is still causing trouble and decide that detention can wait.
